## 2023-11-20 - [Consistent Accessibility Patterns in Replicated Navigation]
**Learning:** In static sites where global navigation is manually replicated across multiple HTML files, accessibility attributes (like ARIA labels) and navigation links must be updated across all instances to maintain a consistent user experience. Failure to do so creates "accessibility debt" and confusing navigation for screen reader and keyboard users.
**Action:** Always perform a global search for navigation patterns when updating one instance of a shared header/footer.
