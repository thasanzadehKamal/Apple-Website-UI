## 2024-05-24 - [Accessibility & Navigation Consistency in Apple UI Clone]
**Learning:** Icon-only navigation elements in this repository (Apple logo, Search, Bag) consistently lack `aria-label` attributes across all page versions. Additionally, the global navigation follows a non-standard semantic pattern (`<ul>` children are `<a>` instead of `<li>`), which must be preserved to avoid breaking layout CSS. Focus indicators are also absent by default.
**Action:** Always apply `aria-label` to the parent `<a>` or `<button>` for icon-only elements and `aria-hidden="true"` to nested icons. Use `:focus-visible` to add accessible focus states without impacting mouse-driven visuals. Ensure localized search tools (e.g., Support search) have unique labels to disambiguate them from global search.
