## 2023-11-20 - Global Navigation Accessibility and Consistency
**Learning:** Global navigation elements are manually replicated across multiple section-specific HTML files (e.g., HomePage.html, Store.html, Support.html), requiring consistent accessibility and link updates across all instances to avoid broken navigation or "mystery meat" icons for screen reader users. The project also uses a non-standard `<ul><a>` structure where links are direct children of the list; changing this to a standard `<li>` structure may break existing CSS.
**Action:** When updating shared components like the navigation bar, identify all occurrences across the project and apply identical `aria-label`, `aria-hidden`, and relative `href` fixes while preserving the existing semantic structure to maintain layout integrity.
