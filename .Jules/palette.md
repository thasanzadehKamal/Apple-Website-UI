## 2025-05-14 - Global Navigation Accessibility and Consistency
**Learning:** In static multi-page sites without component-based architecture, manually replicated navigation bars often suffer from "accessibility rot" where interactive icons lack labels and relative links break over time. Icon-only links specifically fail WCAG without explicit ARIA labels.
**Action:** Always verify ARIA labels for icon-only interactive elements and ensure global navigation links are functional and consistent across all entry points.
